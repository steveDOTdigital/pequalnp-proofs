# Eleven gates for the two-lit graph 2180761

The desk asks whether ten shared AND/OR/NOT gates suffice on the six-input one- or two-lit promise. A complete computational search excludes ten gates. An eleven-gate circuit was checked in Lean on all 36 ordered input pairs. [Posted claim](https://data.pequalnp.com/data/lemma/L-meta-25329.d33a0fe9e04d.json)

Write `a = x₀ ∨ x₁`. The circuit rejects an input if at least one of four conditions holds. Pin 5 is lit, pins 0 and 1 are both lit, pin 2 is lit together with one of 0, 1 and 3, or pin 4 is lit with none of 0, 1 and 2. The final NOT yields the accepting output. Sharing `a` lets these four tests and their combination fit in eleven gates. [Lean construction](Graph2180761Upper.lean)

For the lower bound, each live wire is represented by its truth table on the 21 singleton and unordered pair inputs. With `b` gates left, at most `b+1` live wires can contribute to a single output. Every accepting input must be distinguishable from each rejecting input using some remaining wire. If there is room only for gates combining two wires, all remaining gates must be monotone, and the distinction must be true on the accepting input and false on the rejecting one. The search checks every distinct operand pair, unary NOT and every possible reuse of those operands. Constants, projections and repeated operands can be removed from a minimal circuit for this nonconstant target.
