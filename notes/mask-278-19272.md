# Exactly five gates for mask 278, including NOT gates

The [assigned statement L-meta-19272](https://pequalnp.com/lemma#L-meta-19272) asks for a circuit of at most four gates. Number the row bits r0 through r3 and column bits c0 through c3. On the one-per-side promise, the circuit

    (r0 AND (c1 OR c2)) OR (c0 AND (r1 OR r2))

uses five gates and realizes the sixteen-bit table 278. We prove this optimum allowing AND, OR and NOT. The project has a [checked monotone result](https://pequalnp.com/lemma#L-meta-5480) for the same mask.

## Lower bound

Discard gates outside the output cone. Fold constants and copies, including invalid wire reads, empty gates and unary AND or OR. A live binary AND or OR has two input edges and a NOT has one. If the cone contains r distinct raw coordinates, b binary gates, and t NOTs, connectedness implies 2b+t ≥ r+b+t−1. In particular b ≥ r−1. Equality makes the underlying connected multigraph a tree, so no intermediate or raw bit is used twice.

Without NOT, the cone must contain r0,r1,r2. Each of these rows has a neighbor, whereas row 3 has none. If a nonempty row bit were omitted, switching to row 3 at a neighbor could only increase the seen bits, while the output must fall. The same argument on columns forces c0,c1,c2. Thus at least five binary gates are needed.

With a NOT, two omitted row bits must have identical neighborhoods: the circuit cannot distinguish those rows at any fixed column. The only equal pair is rows 1 and 2. The same holds for columns. Hence at least two raw coordinates on each side are read. A circuit of total size ≤4 with a NOT must therefore have exactly four raw coordinates, three binary gates and one NOT. Its only possible raw support is r0,r3,c0,c3 and its live cone is a tree. A variable occurring once in an AND/OR/NOT formula has a fixed direction of monotonicity, determined by the parity of NOTs on its path to the output.

At either column 0 or column 1, switch from row 1 to row 0. The only visible change is r0 rising. At column 0 the output falls; at column 1 it rises. This contradicts either direction of monotonicity in r0. Thus no four-gate circuit realizes mask 278.

## Independent finite check

The [executable search](mask-278-19272.py) starts with eight raw tables and grants both constants for free. From a reachable set it adjoins any new complement, intersection or union. A repeated value can always be replaced by its earlier wire, so retaining sets of new intermediate values covers circuits with arbitrary sharing. For the last gate, it tests all operations on the available wires. The four search levels had 1, 52, 1,710 and 46,580 reachable prefix sets. None produced 278. The five-gate expression above agrees on all sixteen cells.
