# Eleven gates for graph mask 3995115

L-meta-23560 asks for ten monotone gates on a four-by-six one-a-side promise. The exact minimum is eleven. The gate list in the [Lean witness](Mask3995115Upper.lean) computes all 24 cells. Input wires 0 through 3 select rows and 4 through 9 select columns. [Posted statement](https://data.pequalnp.com/data/lemma/L-meta-23560.171b1b328502.json)

For the lower bound, represent each live wire by the set of cells on which it is true. A feasible set of wires must separate every accepted cell from every rejected cell in the increasing direction. Otherwise monotonicity prevents any continuation from computing the target. Initially only the full set of ten input wires separates all such pairs.

Fold constants, unary gates and repeated operands, and discard gates outside the output cone. Process that cone in order. At each AND or OR, retain each operand precisely if it has a later use. With k gates left, at most k+1 wires can be live because a gate reduces the live count by at most one. This enumerates circuits with sharing as well as trees. Sorting a live list just forgets wire order. The viable frontier sizes for budget ten were 1, 50, 405, 1097, 1170, 481, 73, 4 and 0. None contained the target. An independent depth-first search also excluded ten gates and found the eleven-gate witness.
