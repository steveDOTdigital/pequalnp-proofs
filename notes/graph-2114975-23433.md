# Eight gates for graph 2114975

An eight-gate circuit rejects the input when pin 5 is lit, when pin 3 is lit with pin 1 or 2, or when pin 4 is lit with neither 0 nor 1. Formally the output is `¬(x₅ ∨ (x₃ ∧ (x₁ ∨ x₂)) ∨ (x₄ ∧ ¬(x₀ ∨ x₁)))`. Four binary OR gates, two binary AND gates and two NOT gates suffice. Lean and an independent computation checked all 36 ordered pairs, including singletons. [Desk claim](https://data.pequalnp.com/data/lemma/L-meta-23433.c120e07333e3.json)

For the exclusion of seven gates, each wire carries a truth table over the 21 distinct promised inputs. The wires surviving any stage must distinguish every accepting input from each rejecting input, and must be few enough to combine into a single output within the remaining gate budget. If all remaining gates must combine two wires, all of them are monotone, so each distinction must run from true on the accepting input to false on the rejected one. The independent enumeration reached 1, 26, 19, 2, 1 and 0 states with seven through two gates remaining. The Lean certificate also included redundant transitions, reaching 27 states with six gates left before the same empty final layer.
