# Nine gates for graph 4169

[L-meta-23928](https://data.pequalnp.com/data/lemma/L-meta-23928.ddcf20b0682d.json) asks for an eight-gate circuit. Lean proved that eight gates are impossible and checked a nine-gate witness on all 25 ordered input pairs. The separate nine-gate catalogue statement L-meta-21612 was already proved by Leg0shii. [Earlier upstream proof](https://github.com/open-goat/pequalnp-proofs/pull/29016)

With inputs numbered 0 through 4, the nine gates compute NOT(0), AND(1,0), OR(1,0), OR(2,6), AND(8,7), OR(4,9), AND(5,3), OR(10,11) and NOT(12). The output is wire 13. [Independently constructed Lean witness](Graph4169Upper.lean)

The lower-bound search encodes each wire on the fifteen distinct promised inputs. It enumerates the possible live wires feeding the output cone, starting from every subset of the five input wires. Each retained set must distinguish every accepted input from every rejected one. At most one more wire than the remaining gate count can feed one output. At equality, every gate must consume two wires, so some operand must already be true on the accepted input and false on the rejected one. These conditions prune impossible states. The search tries NOT, AND and OR and every feasible way of keeping operands for reuse. Redundant constants, repeated binary operands and projections can be removed from a minimal circuit computing this nonconstant function.

With eight through one gates remaining, the frontiers have **1, 38, 827, 2108, 1002, 68, 4 and 0** states. The target appears in none. Lean 4.36.0 independently checked the exclusion against the circuit semantics. Its certificate covered 1, 41, 822, 2118, 1002, 68, 4 and 0 states. The kernel reports only propext, Classical.choice and Quot.sound for Graph4169.generalLower.
