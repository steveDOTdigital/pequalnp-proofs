# Eight gates for the five-by-five matrix 25332736

Only three rows contain accepted cells. Row 2 accepts columns 0 and 1, row 3 accepts 0 and 2, and row 4 accepts 3 and 4. The desk asks whether seven binary AND/OR gates suffice. [Posted claim](https://data.pequalnp.com/data/lemma/L-meta-20772.1524de2ae418.json)

A circuit uses one OR to combine the two columns for each row and an AND to select that row. Two more OR gates combine the three row terms, for a total of eight gates. Lean checked all 25 promised inputs. This is an independent proof of [the posted eight-gate bound](https://data.pequalnp.com/data/lemma/L-meta-20699.f64f480d0dd4.json), which already credits [Julleht’s merged proof](https://github.com/open-goat/pequalnp-proofs/pull/27841).

For the lower bound, represent each wire by its 25 output bits. Look at the wires that can still contribute to the output. With `b` binary gates left, there can be at most `b+1` such wires. On every accepting/rejecting input pair, at least one live wire must be true at the accepting input and false at the rejecting input. Enumerating every possible next gate and operand reuse subject to these necessary conditions leaves 1, 10, 19, 9, 1 and 0 states with seven down to two gates left. The kernel checked this exclusion and the eight-gate construction. [Lean proof](Matrix25332736.lean) · [Standalone search and circuit](matrix-25332736-search.py)
