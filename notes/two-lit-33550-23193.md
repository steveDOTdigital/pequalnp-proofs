# Seven gates for the two-lit graph 33550

L-meta-23193 proposes six AND/OR/NOT gates. Its graph is the complete graph on vertices 0, 1, 2 and 3, with isolated vertices 4 and 5. Singletons are rejected. The exact minimum is seven, and a monotone circuit attains it. [Posted statement](https://data.pequalnp.com/data/lemma/L-meta-23193.ba1b1c876d9c.json)

Divide the four clique vertices into pairs {0,1} and {2,3}. Accept when one input from each pair is on, or when both inputs of either pair are on. The circuit uses two ORs for the pairs, three ANDs for these three cases, and two output ORs. Lean checks the monotone gate convention and the exact truth value for every ordered pair of the six indices, including equal indices. [Lean construction](CliqueFourOnSix.lean)

For the lower bound, restrict to the ten singleton or pair inputs using vertices 0 through 3. The two remaining raw wires are always false and can be folded. A NOT gate reads only its first argument; empty, unary and constant gates simplify as in the public circuit semantics. The target on these ten inputs distinguishes all six pairs from all four singletons.

Consider the currently available signals in the live output cone. Each AND or OR combines two signals. NOT complements one. Retain each operand if it still has a use and consume it otherwise. Starting from every viable subset of the four raw indicators therefore includes every possible circuit. The replay additionally allows duplicate-valued or constant gate outputs. A list with m live signals and b gates left needs m ≤ b+1. Opposite target values must have distinct vectors of live signals. When m=b+1, each gate must consume two operands and retain neither, so the remaining computation must be monotone. In that case, also reject a list when an accepted vector is componentwise below a rejected vector.

With six gates, the number of distinct viable signal lists from depth zero onward is 1, 20, 147, 129, 42, 0. No list contains the target at an earlier depth. A separate depth-first search also ruled out six on all 21 unordered singleton and pair cases. The numerical exclusion has a standalone Python replay and has yet to be formalized in Lean.
