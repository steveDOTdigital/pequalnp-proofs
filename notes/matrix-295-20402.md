# Seven gates for the three-by-four matrix 295

[L-meta-20402](https://data.pequalnp.com/data/lemma/L-meta-20402.8e416d7a41e8.json) asks for a circuit of at most six binary AND/OR gates on the one-per-side promise. Lean proved that the minimum is seven. [Formal proof](Matrix295.lean)

The first row accepts columns 0, 1 and 2. The second accepts only column 1, and the third only column 0. A seven-gate construction uses three terms. They are row 0 AND column 2, (row 0 OR row 1) AND column 1, and (row 0 OR row 2) AND column 0. Two final OR gates combine them. Lean checked the resulting output on all twelve inputs.

For the lower bound, encode each wire by its twelve-bit truth table. If the output accepts one input and rejects another, some wire feeding the remaining monotone circuit must be true on the first and false on the second. With `b` binary gates left, at most `b+1` wires can feed a single output. Enumerating all feasible live-wire sets and every legal next gate excludes circuits of size at most six. The kernel checked 2, 27, 52, 30, 6 and 0 states with six down to one gate remaining, allowing constants, projections, repeated operands and reuse. A separate search eliminating redundant gates also reached an empty set.

Lean 4.36.0 checked `Matrix295.exactLower` and `Matrix295.upper`. The related four-by-four theorem uses a different input dimension. [Four-by-four catalogue record](https://data.pequalnp.com/data/lemma/L-meta-5927.1d63a7188701.json)
