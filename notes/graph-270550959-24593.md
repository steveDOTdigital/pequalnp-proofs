# Nine gates for graph 270550959

The posted statement asks whether eight shared AND/OR/NOT gates suffice for graph 270550959 on six inputs. Lean checked a nine-gate witness and proved that eight gates cannot realize the graph on the one- or two-lit promise. [Desk claim](https://data.pequalnp.com/data/lemma/L-meta-24593.243d2f92bcbb.json)

The witness shares the signal `s = x₂ ∨ x₀`. Its output is `¬((¬x₀ ∧ (x₅ ∨ (x₃ ∧ s))) ∨ (x₄ ∧ (x₃ ∨ s)))`. Computing the shared signal once gives nine gates. The independent replay checked all 36 ordered inputs, including repetitions.

For the lower bound, the twenty-one distinct promised inputs give a truth table for each wire. A candidate set of live wires must separate every accepting input from each rejecting input and must be small enough to combine into a single output within the remaining gate budget. When every remaining gate is needed to combine two wires, there is no room for a NOT, so the required separation becomes directional. The independent enumeration checked every next gate and possible reuse of its operands. Its layer sizes were 2, 102, 1,400, 2,189, 484, 21 and 0 with eight through two gates left. The kernel certificate checked redundant transitions as well, reaching 2, 108, 1,401, 2,199, 484, 21 and 0 viable states.
